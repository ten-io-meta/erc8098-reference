# ERC-8098 Reference Implementation

Standalone reference candidate for [draft ERC-8098](https://github.com/ethereum/ERCs/pull/1390): non-increasing ERC-20 total supply, irreversible burns, and single canonical ERC-20 balance/supply accounting.

**Status:** work in progress; not audited or certified. No coupling to OECL, TEN.IO token economics or ERC-8060.
